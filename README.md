Платформа для сбора работ на конкурсы с ролевой системой (участник, жюри, администратор).


Возможности

Три роли пользователей: участник, жюри, администратор
Управление конкурсами: создание, редактирование, удаление
Загрузка файлов: поддержка PDF, ZIP, PNG, JPG (до 10MB, до 3 файлов)
Проверка работ: жюри может просматривать и оценивать работы
Комментарии: обратная связь по работам
Статистика: для администраторов
Очереди: асинхронная обработка файлов
